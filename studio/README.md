# Kolibri Studio

Отдельная студия работает на Node.js 22 или новее. Установите зависимости командами `npm ci --prefix mobile` и `npm ci --prefix studio`, создайте окружение `python3 -m venv studio/.venv` и установите зависимости `studio/.venv/bin/pip install -r studio/requirements.txt`, затем запустите `node studio/server.mjs`. Откройте порт 4175; изменить порт можно переменной `PORT`.

Сервер не требует пароля и позволяет изменять каталог и загружать изображения. Используйте его только в доверенной сети или защищённом окружении: любой посетитель с доступом к студии может изменять данные и инициировать коммит, push и публикацию APK от имени подключённого GitHub. Защита запросов между сайтами не заменяет авторизацию.

Изменения записываются в `web/app/catalog.json`, изображения — в `web/app/media/`. Чтобы включить их в автономное приложение и стенд, выполните `npm run build:stand --prefix mobile`. Студия и её сервер не входят в мобильную сборку. Кнопка APK собирает каталог и медиа, коммитит их в текущую ветку arena, отправляет её на GitHub и ожидает конкретный workflow. Для работы нужны git, gh с авторизацией и права на push и публикацию релизов. Имеющиеся staged-изменения и несохранённые изменения кода сборки блокируют запуск. Скачивание и QR ведут на конкретный опубликованный релиз. Сборка HTML доступна отдельно. Встроенный парсер извлекает текстовый слой и таблицы PDF; сканы без текста требуют внешнего OCR. Автоматическое распознавание не гарантирует полноту: обязательно сверяйте разделы и номера страниц с оригиналом. ИИ обрабатывает распознанные пункты и шаги партиями и добавляет пояснения рядом с исходным текстом; это не заменяет сверку и не дополняет каталог деталей. Если API недоступен, используется встроенный разбор. Ключ не сохраняется, а извлечённый текст отправляется указанному провайдеру. Внешние запросы к ИИ выполняются браузером; провайдер должен разрешать CORS.

Настройки ИИ общие для чата и разбора PDF. По умолчанию используется llm7, при ошибке — резервный шлюз Pollinations; доступность, модели, лимиты и бесплатный доступ определяются соответствующими сервисами и не гарантируются. Для альтернативных провайдеров нужен собственный ключ, который не сохраняется. Текст чата и извлечённые сведения отправляются провайдерам. При недоступности обоих сервисов PDF разбирается локально, а чат сообщает об ошибке без автоматических правок.

В чате изменения сохраняются с проверкой версии и могут затрагивать название машины, текущие регулировки, пункты раздела и поля существующих деталей. Изменение структуры каталога деталей через чат пока не поддерживается. Значения и процедуры, предложенные ИИ или изменённые пользователем, необходимо сверять с оригинальным руководством.
