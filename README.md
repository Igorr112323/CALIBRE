# КАЛИБР — локальный справочник для механизатора

КАЛИБР — Android-приложение и локальный сервер-каталог. Экран приложения упаковывается в APK; телефон не открывает публичный веб-сайт. Админка и операции с исходными данными остаются на компьютере-сервере. Телефон получает только опубликованный каталог и может отправить только ожидающие отзывы и вопросы.

## Этап 3: что сделано

- Экранная структура и визуальный стиль сверстаны по `design/prototype.html`: главная, поиск, схема, вкладки узлов/проблем, карточка узла, пошаговая проблема, фото-демо и настройки.
- Неподтверждённые значения из прототипа не переносятся как инструкции. Учебные карточки имеют заметную пометку **ДЕМО**; технические значения в образце — **ДЕМО**, без выдуманных параметров.
- Сервер отдаёт опубликованный каталог через версионируемую синхронизацию. На Android он сохраняется в SQLite; в браузерном предпросмотре используется IndexedDB с резервом на `localStorage`.
- Отзывы **«Помогла карточка?»** и вопросы сохраняются локально, отправляются при возвращении сети и повторно не создаются при безопасном повторе запроса.
- Настройки содержат адрес сервера, проверку связи, синхронизацию, дату последней синхронизации и счётчики очереди.
- Собираются два готовых файла для проверки: Android APK и автономный Windows EXE. EXE сам запускает веб-страницу и открывает браузер; Python, Node.js и ручное открытие HTML не нужны.
- EXE запускает два раздельных слушателя: предпросмотр страницы — только на `127.0.0.1`, а ограниченный API для телефона — в локальной сети. Админка и предпросмотр недоступны с телефона.
- Добавлены `build_apk.bat` для локальной Android-сборки и подробная инструкция: [`mobile/README.md`](mobile/README.md). Готовые файлы тестовых сборок публикуются в [релизах проекта](https://github.com/Igorr112323/CALIBRE/releases).

**ДЕМО не является проверенным руководством.** В текущем наборе нет реальных характеристик КРН-2,1 и нет верифицированных настроек. Внешний вид элементов фото-поиска — симуляция; камера или распознавание изображений пока не выполняются. APK/EXE собираются CI, но их физическая установка и тест на устройствах владельца ещё не выполнены.

## Технологии и свободные библиотеки

Версии зафиксированы в `requirements.txt`, `requirements-desktop.txt`, `mobile/package-lock.json` и папке локального PDF.js. Подробности лицензий и сохранённые notices: [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

- **FastAPI + Uvicorn** — локальный API.
- **SQLAlchemy + SQLite + Alembic** — серверная база данных и миграции схемы.
- **Capacitor 8 + Vite** — сборка локального интерфейса в APK и браузерный предпросмотр.
- **PyInstaller** — упаковка локального сервера, HTML-ресурсов и Python в один Windows EXE.
- **@capacitor-community/sqlite** — нативное локальное хранилище Android.
- **@capacitor/network** — обнаружение восстановления сетевого соединения на Android.
- **IndexedDB / localStorage** — браузерное хранение предпросмотра и резерв.
- **pypdf + pdfplumber** — извлечение текста/таблиц PDF; **pypdfium2 (PDFium)** — локальный рендер страниц для OCR/просмотра. PyMuPDF не используется.
- **PDF.js 6.4.299** — локальный просмотрщик административной части; CDN не нужен.
- OCR/поиск и другие прямые Python-зависимости указаны в `requirements.txt` и `THIRD_PARTY_NOTICES.md`. Платных сервисов и AI API-ключей этот этап не требует.

Сведения о лицензиях — техническая проверка метаданных и notices, не формальное юридическое заключение. Перед коммерческим выпуском нужно заново проверить фактический транзитивный состав сборки и права на каждое загруженное руководство/изображение. Лицензия будущей модели/весов ИИ будет рассмотрена отдельно, когда будет выбрана модель.

## Сервер на Windows

1. Установите Python 3.11+ с `python.org`, отметив **Add Python to PATH**.
2. Запустите `run.bat`. При первом старте устанавливаются Python-зависимости; после их подготовки сервер может работать без интернета.
3. Разрешайте входящие подключения Python только в частной сети. Не включайте проброс порта на маршрутизаторе.
4. Сервер напечатает адрес админки (только на компьютере: `http://127.0.0.1:8765/admin`) и LAN-адрес для приложения, например `http://192.168.1.20:8765`.
5. Подробная проверка связи с телефоном приведена в `mobile/README.md`.

База находится в `data/calibre.sqlite3`, загрузки — в локальных папках данных; эти файлы не добавляются в Git. Серверная админка не доступна извне компьютера-сервера. Публичного пользовательского веб-сайта нет.

## Готовая Windows-страница без установки

Скачайте **один `CALIBRE-PC.exe`** из последнего [тестового релиза](https://github.com/Igorr112323/CALIBRE/releases) и запустите двойным щелчком. EXE сам создаёт демонстрационную базу и автоматически открывает готовую HTML-страницу в браузере Windows. Python, Node.js, Android Studio и отдельное скачивание HTML не нужны. Небольшое окно КАЛИБР показывает адрес API для телефона; закройте его, чтобы завершить работу. Данные сохраняются в профиле Windows.

Страница предпросмотра доступна только через loopback на этом компьютере. Отдельный порт API принимает от телефонов только чтение опубликованного каталога и очереди отзывов/вопросов; админка и сама HTML-страница через LAN закрыты. Для связи телефона с EXE выберите **частную сеть** в Windows Firewall, если Windows спросит. Для разработчика остаются `preview_app.bat` и `run.bat`; обычному просмотру страницы они не требуются.

В APK используется нативная SQLite, а в исходном browser-dev preview — IndexedDB с резервом `localStorage`.

## Сборка и установка APK

Готовый тестовый APK публикуется в [релизах проекта](https://github.com/Igorr112323/CALIBRE/releases); локальная сборка через `build_apk.bat` кладёт его в `dist\CALIBRE-debug.apk`. Пересборка на Windows требует Node.js 22 LTS, Android Studio/SDK и JDK 21, но для установки уже готового APK эти инструменты на телефоне не нужны. После установки укажите LAN-адрес сервера и синхронизируйте каталог.

Пошаговая установка APK, проверка HTTP/Firewall и очереди в авиарежиме: [`mobile/README.md`](mobile/README.md). CI-сборка APK проходит на GitHub Actions; физический телефон владельца ещё не проверен.

## Проверки в репозитории

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
cd mobile
npm ci
npm run build
npm audit
```

Выполненные автоматические проверки: тесты API/безопасности/очередей и PDF, компиляция Python, сборка веб-ресурсов Vite, Capacitor sync, `npm audit` и `git diff --check`. Результат актуальных тестов фиксируется в итоговом отчёте этапа. Эти проверки не заменяют испытание APK и подключение телефона к вашей сети.
