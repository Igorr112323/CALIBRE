# КАЛИБР — локальный демо-срез ГРН-471 Kolibri v4

Ограниченная проверка этапов 4–6: PDF загружается на ПК, локально разбирается в фоне, карточки проходят проверку администратора, а телефон получает только выбранные опубликованные сведения. Это демо, не готовая универсальная база инструкций.

## ПК-админка и PDF

Windows EXE открывает Kolibri в отдельном окне приложения с короткой анимацией запуска — без адресной строки и отдельного браузера. Приложение включает локальный сервер и ПК-админку; телефонный интерфейс в EXE не входит. Тот же сервер отдаёт мобильному APK ограниченный LAN API, а телефонное приложение запускается только на Android-телефоне. Исходный PDF и извлечённые страницы остаются на ПК-сервере пользователя. Для точного руководства ГРН-471 Kolibri v4 начальный охват — текст руководства PDF-стр. 4–33; каталог деталей PDF-стр. 34–56. Каталог годится для названий деталей, но не для регулировочных норм.

В админке можно задать простой вопрос по загруженному руководству: ответ сопровождается ссылкой на страницу, а при нехватке подтверждения это явно сообщается. Подсказка не становится проверенным фактом автоматически. Администратор вручную добавляет фото и узлы, проверяет карточку и отдельно включает публикацию; черновики не передаются в APK. Пробелы руководства не заполняются догадками.

Админка открывает каталог карточек в стиле главного экрана APK: кнопка «Создать новую карточку» и список машин. При создании нужны название, фото и хотя бы одна подписанная отметка-узел; PDF можно приложить по желанию. После сохранения карточка открывается с теми же тремя вкладками, что и в телефоне: «Схема», «Узлы», «Неисправности». В них редактируются сведения, точки, узлы и карточки неисправностей. Любое изменение опубликованной карточки возвращает её в черновики, поэтому её нужно проверить и опубликовать заново. Передача внутренних фото в APK по LAN выключена по умолчанию и разрешается отдельно для каждого фото. На данный момент Windows EXE **не содержит Ollama и веса AI-модели и не устанавливает их автоматически**; локальная генерация ответов требует отдельной настройки runtime и модели. Каталог данных не является обученной моделью, а подсказки по руководству не считаются проверенными фактами.

Детали реализации, проверок, границ цитирования и локального benchmark — [`ADMIN_AI.md`](ADMIN_AI.md).

## Android APK, офлайн и sync

APK включает подготовленный текстовый демо-каталог **«ГРН-471 Kolibri (демо)»** и доступен офлайн. Существующие мобильные экраны и дизайн из `stage3-test-19` заморожены: структура, палитра, шрифты, анимация, иконка и заставка не меняются; можно только заполнить существующие области демо-контентом и добавить согласованную нажимаемую SVG-схему во вкладке «Схема». Вопросы по PDF находятся только в админке ПК.

При подключении к компьютеру по LAN телефон синхронизирует опубликованный каталог. Фото с правами `internal_only` передаётся только если администратор явно отметил разрешение LAN-sync, и только для опубликованного узла; это не публикация в интернете. PDF, черновики и админские функции наружу не выдаются. Локальный поиск, кэш согласованных фото, очередь отзывов и их отправка после восстановления связи поддерживают офлайн-работу.

## Файлы и сборки

Workflow `.github/workflows/build-android.yml` собирает Android APK и отдельный Windows EXE-сервер для админки, выполняет Windows self-test и публикует prerelease с контрольными суммами. В ПК EXE нет мобильного интерфейса: он отдаёт только локальную админку и LAN API для APK на телефоне. [Список релизов и их файлов APK/EXE](https://github.com/Igorr112323/CALIBRE/releases). Для локальной сборки APK используйте инструкцию [`mobile/README.md`](mobile/README.md). Windows-зависимости перечислены в `requirements-desktop.txt`; PyInstaller собирает админку, API и локальные Python-компоненты.

Исходный PDF, извлечённые фигуры/кропы, локальная база и gold-эталон не входят в Git или релиз. Пользователь загружает свой PDF только после запуска EXE.

## Локальный сервер разработки

```bash
python -m pip install -r requirements.txt
python server.py
```

Админка: `http://127.0.0.1:8765/admin`. Данные сохраняются в `data/` при запуске из исходников; в Windows EXE — в `%LOCALAPPDATA%\CALIBRE`. Для LAN-синхронизации подключите ПК и телефон к одной частной Wi-Fi-сети и не открывайте админ-порт в интернет.

## Автоматические проверки

```bash
.venv/bin/python -m compileall -q calibre server.py desktop_launcher.py migrations/versions
.venv/bin/python -m unittest discover -s tests -v
node --check web/admin/admin.js
node --check web/admin/pdf-viewer.js
```

Результаты unit-тестов, Windows/Android сборок, gold-сверки и benchmark публикуются отдельно после их фактического запуска. Успех тестов в исходниках не означает, что APK установили на телефон или что Windows EXE запущен владельцем.
