# Kolibri — справочник сельхозтехники

Офлайн Android-справочник для студентов факультета механизации и механизаторов: узлы машин, регулировки, обслуживание и поиск неисправностей. Данные встроены в приложение, подключение к сети не требуется.

Сейчас в каталоге представлен материал по граблям ГРН-471. Он автоматически проверен, но не сверён человеком: перед работой обязательно обращайтесь к руководству производителя и соблюдайте требования безопасности.

## Сборка

Нужны Node.js 22, JDK 21 и Android SDK. В Windows запустите `build_apk.bat`: отладочный APK появится в `dist/Kolibri-Mehfak.apk`. Команды для других платформ приведены в [mobile/README.md](mobile/README.md). APK также доступен как артефакт сборки GitHub Actions.
