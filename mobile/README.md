# Android APK Kolibri — демо-срез ГРН-471, этапы 4–6

Приложение упаковывает интерфейс, подготовленный текстовый каталог и офлайн-данные локально в APK через Capacitor. PDF и извлечённые из него изображения в APK не попадают. Экранная композиция `stage3-test-19` заморожена: этот срез не добавляет телефонных экранов или чата; вопросы к PDF доступны только в админке ПК.

## Сборка и установка

APK и EXE публикуются отдельно в [списке релизов](https://github.com/Igorr112323/CALIBRE/releases). APK — мобильное приложение только для Android-телефона. Windows EXE — сервер и админка ПК, он не запускает мобильный интерфейс. APK является отладочной тестовой сборкой, а не подписанным коммерческим приложением; Android может попросить разрешить установку из выбранного источника. EXE может показать предупреждение SmartScreen, поскольку не подписан коммерческим сертификатом.

Для локальной сборки APK в Windows нужны Node.js 22 LTS, Android Studio/SDK и JDK 21. Запустите `build_apk.bat`; результат: `dist\Kolibri-GRN-471-demo.apk`. Скрипт выполняет `npm ci`, Vite build, Capacitor sync и `assembleDebug`.

Установка из локальной сборки:

1. Передайте APK на телефон по USB или другим личным способом.
2. Разрешите установку для выбранного файлового менеджера и подтвердите установку.
3. Откройте Kolibri. Демо-каталог «ГРН-471 Kolibri (демо)» встроен и доступен офлайн.
4. Для LAN-синхронизации запустите EXE на ПК, подключите ПК и телефон к одной доверенной частной Wi‑Fi-сети и укажите в существующих настройках приложения адрес API, показанный EXE.
5. Не пробрасывайте порт в интернет. Разрешение Windows Firewall — только для частной сети.

## Офлайн и LAN-синхронизация

- Каталог, поиск, схема и очередь отзывов сохраняются локально на Android (SQLite с резервным хранилищем); очередь отправляется при восстановлении сети и не теряется при перезапуске.
- LAN API передаёт только опубликованный каталог. PDF и админка через LAN закрыты.
- Внутреннее фото передаётся на телефон только после явного разрешения администратора «Разрешить передачу в приложение по локальной Wi‑Fi/LAN-сети» и только для опубликованного узла. В базе это остаётся `internal_only`/непубличным; поток доступен только через мобильный LAN API. На телефоне сжатая копия кэшируется локально для офлайн-доступности данных. Непомеченные фото остаются только на ПК.
- Мобильное приложение не запрашивает Ollama и не содержит AI-веса; вопросы по документам не переносятся на телефон.

## Текущий demo-контент

APK содержит подготовленный текстовый материал по одному руководству: ГРН-471 Kolibri v4. Контент включает узлы рисунка 1.1 и раздела 2.3; регулировки разделов 2.3/5/6 и безопасность; все 6 строк таблицы 10.1; ЕТО/хранение/смазку и отдельно помеченные пробелы источника. Числовые нормы сопровождаются источником/цитатой и статусом машинной/человеческой проверки. Каталог деталей предназначен только для названий деталей, не для эксплуатационных регулировок.

Существующие структура экранов, цвета, шрифты, компоновка, анимация, иконка и заставка из `stage3-test-19` не меняются. Разрешено только заполнение существующих областей и нажимаемая SVG-схема в существующей вкладке «Схема». Исходный PDF, локальный gold-файл и извлечённые кропы не включаются в APK/EXE/релиз.

## Разработчику

Из `mobile/`:

```powershell
npm ci
npm run build
npx cap sync android
```

Изменения мобильного интерфейса проверяются тестами `tests/test_mobile_app.py`; перед выпуском требуется физически проверить установку APK, поиск без сети, сохранение очереди и LAN-синхронизацию с реальным телефоном. Успешная CI-сборка не заменяет этот тест.
