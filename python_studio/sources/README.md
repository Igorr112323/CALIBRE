# Исходники Android-оболочки

`web/app/` содержит исходный веб-интерфейс, стили, рисунки и заставку. `mobile/` содержит Capacitor, Gradle-проект и Android-ресурсы. Эти исходники сохранены для разработчика и не используются при обычной сборке каталога: студия подставляет данные в готовый `apk_template/kolibri-shell.apk`. Пересборка самой оболочки требует установленного Node.js, Android SDK и Gradle.
