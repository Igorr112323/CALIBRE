ТОЛЬКО ЛОКАЛЬНЫЙ OLLAMA

Модели без облака

Проверяем…

Разбор PDF и вопросы к документу выполняются на этом ПК через localhost. После загрузки модели соединение с интернетом не используется. Без Ollama готовые карточки и локальная админка продолжают работать.

Рекомендуемый профиль: Qwen3 8B Q4 для русского текста и BGE-M3 для многоязычного поиска. Реальная скорость на ПК пользователя не измерялась. Если Ollama не установлена, установите её отдельно; PDF не покидает этот компьютер.
